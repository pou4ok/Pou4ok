## 🧠 Шпаргалка React-паттернов

| Паттерн            | Метод                                          | Возвращает     |
|--------------------|------------------------------------------------|----------------|
| Добавить элемент   | `[...arr, newItem]`                            | новый массив   |
| Удалить элемент    | `.filter(x => x.id !== id)`                    | новый массив   |
| Изменить элемент   | `.map(x => x.id === id ? {...x, ...} : x)`     | новый массив   |
| Обновить объект    | `{ ...obj, key: value }`                       | новый объект   |
| Извлечь поля       | `const { a, b = def } = obj`                   | переменные     |
| Остаток            | `const { a, ...rest } = obj`                   | новый объект   |
| Итог               | `.reduce((acc, x) => acc + x, 0)`              | число          |
| useState           | `const [val, setVal] = useState(init)`         | кортеж         |

## ⚠️ Исправленные ошибки исходного PDF

1. `console.Log` → `console.log`
2. `"MacBook Air M3 125000)` → `"MacBook Air M3", 125000)`
3. `item.id = removeId` → `item.id !== removeId` (присваивание → сравнение)
4. `item.id = targetId` → `item.id === targetId` (та же ошибка)
5. `"Научники"` → `"Наушники"`
6. `⇒` (математический символ) → `=>` (стрелка JS)
7. `py6.` → `руб.`
8. `==` → `===` для проверки ссылочной идентичности
9. Дублирование элементов в `initialCart`

## 🎯 Главное правило React

> Никогда не мутировать стейт напрямую — только создавать новые объекты
> и массивы через Spread и методы трансформации.
